# Documentation consistency review prompts

When reviewing a module, compare:

- module-level overview versus item behavior;
- README/reference/task guide versus current API;
- error/panic docs versus actual branches;
- examples versus current public import paths;
- capability/maturity claims versus current tests/features;
- historical benchmark/audit links versus current claims;
- terminology against the glossary.

Fix current guides/contracts when stale. Preserve historical reports as
revision-bound records instead of rewriting their past results.
