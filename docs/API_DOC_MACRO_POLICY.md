# Macro-generated API documentation policy

Source regex discovery can miss callables generated by declarative/procedural
macros. These APIs still count when they are externally reachable.

The compiler/rustdoc reconciliation phase must therefore discover generated
public items and associate them with their originating macro/source where
possible. Macro documentation should explain generated names, signatures,
constraints and expansion-visible behavior; generated item Rustdoc should be
usable without requiring the user to inspect expansion internals.

Examples should invoke the macro through its public interface and assert the
resulting API behavior. A successful macro expansion is not by itself a semantic
example of the generated callable.
