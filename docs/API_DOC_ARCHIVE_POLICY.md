# Historical documentation archive policy

Audit reports, benchmark results and research notes are retained as evidence of
the revision they describe. Do not rewrite old measurements/claims to match
current code; add a newer report or correction with revision/date instead.

Current guides should avoid linking historical material as if it were an
undated guarantee. Generated current lexicons should exclude archived source
snapshots/vendored external internals unless they are intentionally part of the
public API inventory.
