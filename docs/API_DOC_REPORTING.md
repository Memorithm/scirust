# Documentation progress reporting

Each #1431 progress report should state:

- exact source revision/PR;
- packages/modules reviewed;
- public callables covered by the reviewed policy;
- summaries added/improved;
- ordinary examples observed and actually executed;
- runtime/test defects found and fixed;
- documentation-debt delta;
- applicable CI status;
- remaining high-priority scopes and qualification discrepancies.

Do not report "all functions documented" until compiler-derived reachability,
semantic contract review and example execution meet the repository-wide
definition of done. Percentages must include numerator, denominator and metric
definition.
