# Geometry API review prompts

For public geometry APIs, document/review:

- coordinate system/order and units;
- handedness/orientation/sign convention;
- angle units;
- normalization assumptions;
- degeneracy/collinearity/singularity behavior;
- tolerance convention for predicates;
- output ordering/orientation;
- numerical robustness limits.

Examples should use simple analytic geometry plus a degenerate/boundary case.
Robust predicate claims require appropriate numerical/reference evidence.
